おとも手帖(ブラウザ版) はじめに(自分用)

これは、iPhone・iPad・パソコンのブラウザで動く おとも手帖 です。
いちど開いてホーム画面に追加すると、ネットがなくても動きます(オフライン対応)。
データは、その端末の中に入ります。

■ 1. ブラウザ版を置く(GitHub Pages)  ※いちど だけ
 GitHub の otomo-web(公開)に、このフォルダの 6つのファイルを入れる:
   index.html / sw.js / manifest.webmanifest / icon-180.png / icon-192.png / icon-512.png
 (すでに入っている index.html などは、同じ名前で上書きする)
 Settings → Pages で Branch を main / (root) にして Save。
 数分後、https://(ユーザー名).github.io/otomo-web/ で開けます。
 ※開けない(404)ときは、Code タブで README を1つ作って Commit すると、公開が動き出します。

■ 2. iPhone・iPad で使う
 Safari で上のURLを開く → 共有ボタン → 「ホーム画面に追加」。
 そのあとは、ホーム画面のアイコンから開きます(ネットがなくても動きます)。
 ・新しい版にしたいときは、ネットがある所で、アイコンから開くと入れかわります。
   (入れかわったら、いちど閉じて、開きなおす)
 ・Safari で何日も開かないと、データが消えることがあります。必ず「ホーム画面に追加」して
   使ってください。

■ 3. 同期する(2つの方法。どちらか、または両方)
 A. 同期ファイル(アカウント不要)
    設定 → 「同期ファイル」 → 書き出す / 取り込む(または、文字にしてコピー / 貼りつけ)
 B. GitHub(自動に近い)
    設定 → 「GitHubで同期」 → リポジトリ(ユーザー名/otomo-data・非公開)・トークン・同期するもの
    左下の「同期」ボタンで、いま同期。起動したときに自動で同期もできます。
    ※otomo-data は必ず非公開(Private)にして、README を1つ作っておく。
    ※トークンは、Fine-grained tokens で otomo-data だけを選び、Contents を Read and write に。

■ きまり
 ・変えたほうが採用されます。両方で変えたときは新しいほうを残し、もう一方は「(競合)」のコピーに。
 ・消したものは、同期した先でも消えます。まとまった数が消えるときは確認が出ます。
 ・画像・お金・依頼・設定は、同期しません。
 ・ときどき、設定の「本体を保存」で、バックアップを残してください。
